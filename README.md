# 📚 Library

**Library** is my very first website — a single-page responsive web application created as part of the [JavaScript Front-End Pre-School](https://rs.school/js-stage0/) course at **Rolling Scopes School**.

This project simulates a modern public library with user registration, a personal profile, curated book lists, and a cozy coffee shop section.

## 🌟 Features

- 🔐 User authentication (sign up/login via email or library card)
- 👤 Personal profile with visit stats, borrowed books, and digital library card
- 📖 Seasonal book recommendations (Staff Picks)
- ☕ Coffee shop menu with prices
- 🕒 Contact info and working hours
- 📱 Responsive design for desktop and mobile

## 🎯 Purpose

The main goal of this project was to practice and demonstrate core front-end development skills:

- Semantic **HTML5**
- Layout and styling with **CSS3**
- Form handling and basic **JavaScript** interactivity
- Simple state management (login/profile)
- Clean and accessible **UI/UX**

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid)
- Vanilla JavaScript (ES6)
